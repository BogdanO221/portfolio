# Bogdan Obradović — Portfolio

Lični portfolio sajt — Next.js 15 + React 19.

## Pokretanje

```bash
npm install
npm run dev
```

Otvori [http://localhost:3000](http://localhost:3000).

## Deploy

Najjednostavnije — push na GitHub i poveži repo sa [Vercel](https://vercel.com/new). Vercel automatski detektuje Next.js i builduje.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- next/font (Space Grotesk, JetBrains Mono)
